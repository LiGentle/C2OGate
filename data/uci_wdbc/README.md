# UCI Breast Cancer Wisconsin (Diagnostic) data

Files `wdbc.data` and `wdbc.names` are the Breast Cancer Wisconsin
(Diagnostic) dataset distributed by the UCI Machine Learning Repository.

- Creators: William Wolberg, Olvi Mangasarian, Nick Street, and W. Street.
- UCI dataset identifier: 17.
- DOI: <https://doi.org/10.24432/C5DW2B>.
- Source: <https://archive.ics.uci.edu/dataset/17/breast-cancer-wisconsin-diagnostic>.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).

- `wdbc.data` SHA-256: `d606af411f3e5be8a317a5a8b652b425aaf0ff38ca683d5327ffff94c3695f4a`.
- `wdbc.names` SHA-256: `840e04e3f20f8a5b326892f3b9cbc01c4cd6f7e6c597630b701ef6c0ac79f5ef`.

The paper uses the data only as a real-data numerical benchmark. It makes no
medical, diagnostic, or clinical-performance claim.
